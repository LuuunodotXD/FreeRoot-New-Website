Em Desenvolvimento Ativo

Não é um fork!

O FreeRoot Linux é uma distribuição independente, desenvolvida inteiramente por voluntários brasileiros.

Diferentemente de muitas outras distros, o FreeRoot não é uma modificação de uma distro existente. O gerenciador de pacotes e o sistema de build foram escritos do zero por brasileiros.

Release estável

O FreeRoot foca em estabilidade, ao invés de ser bleeding-edge. Instale uma vez, atualize rotineiramente e com segurança.

Graças ao nosso sistema de build contínuo, novo software é compilado em pacotes binários assim que as mudanças são enviadas para o repositório.

Características principais

  • Base feita do zero
  • Controle total sobre cada componente
  • Foco educacional e experimental
  • Otimizado para performance
  • Filosofia DIY
  • Transparência total do sistema
  • Comunidade aberta e colaborativa

Informações técnicas

Sistema feito do zero, com compilação manual de todos os componentes. Durante a construção, é comum encontrar dependências que precisam ser resolvidas manualmente. Você pode observar o fetch ao lado direito desse texto

Sistema atual

Kernel 4.19.66-LFS, Shell dash, arquitetura x86_64

Outras informações

Compilador Clang, Init system openRC, library glibc
